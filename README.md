# Messages Demo — School Project

Static GitHub Pages package.

## Publish
1. Put all files in the root of a GitHub repository.
2. GitHub → repository → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: /(root), then Save.
5. Open the GitHub Pages URL in Safari.
6. On iPhone: Share → Add to Home Screen → enable "Open as Web App" → Add.
7. Launch from the Home Screen for standalone mode.

The page contains a permanent DEMO / SCHOOL PROJECT watermark and a no-valid-ticket notice.
